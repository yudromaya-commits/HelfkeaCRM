# Канбан-доска для RepresSales2

## 📋 Обзор

Добавлена канбан-доска как вторая вкладка в разделе "Календарь". Канбан предоставляет визуальное представление задач по статусам с возможностью фильтрации и поиска.

## 🎯 Функции

### 1. **Две вкладки в календаре**
- **Календарь** - традиционный вид по дням
- **Канбан** - доска с колонками по статусам

### 2. **5 колонок статусов** (маппинг с 1С)
- 🟠 **К выполнению** - статусы: "Назначена", "Новая"
- 🔵 **В работе** - статусы: "В работе", "Выполняется"
- 🟢 **Выполнено** - статусы: "Выполнена", "Завершена", "Отменена"
- 🔴 **Просрочено** - статусы: "Просрочена"
- ⚫ **На проверке** - временный статус (мапится в "В работе" для 1С)

### 3. **Фильтрация и поиск**
- 🔍 **Поиск по тексту** - название, описание, статус, исполнитель
- 👤 **Фильтр по контрагенту** - выбор конкретного контрагента
- 📅 **Фильтр по дате**:
  - Все даты
  - Сегодня
  - Завтра
  - Эта неделя
  - Просроченные

### 4. **Статистика**
- Общее количество задач
- Количество важных задач (❗)
- Количество просроченных задач (⏰)

### 5. **Визуальные особенности**
- Цветовые коды для каждого статуса
- Иконки для важных и просроченных задач
- Адаптивный дизайн
- Drag & drop (визуальный, без изменения данных в 1С)

## 🚀 Использование

### Переключение между вкладками
1. Откройте раздел "Календарь" в навигации
2. Вверху увидите две вкладки: "Календарь" и "Канбан"
3. Нажмите на "Канбан" для переключения

### Работа с фильтрами
1. Нажмите кнопку "Фильтры" в правом верхнем углу
2. Используйте поля для настройки:
   - **Поиск** - введите текст для поиска
   - **Контрагент** - выберите из списка
   - **Дата** - выберите период
3. Нажмите "Очистить фильтры" для сброса

### Просмотр задач
- **Карточка задачи** показывает:
  - Название задачи
  - Краткое описание
  - Контрагента (если есть)
  - Дату выполнения
  - Исполнителя
  - Статус и важность

- **Клик по карточке** открывает детальный экран задачи

## 🔧 Технические детали

### Архитектура
- **Модель**: `KanbanStatus.kt` - маппинг статусов 1С ↔ канбан
- **UI компоненты**:
  - `EnhancedKanbanView.kt` - основная реализация
  - `KanbanUtils.kt` - вспомогательные функции
  - `CalendarWithKanbanView.kt` - обёртка с вкладками
- **Интеграция**: использует существующие `TaskViewModel` и `TaskRepository`

### Особенности реализации
1. **Только чтение** - канбан не изменяет данные в 1С
2. **Локальная фильтрация** - все фильтры применяются локально
3. **Автообновление** - данные загружаются при открытии канбана
4. **Совместимость** - работает с существующей навигацией и детальными экранами

## 🐛 Известные ограничения

1. **Drag & drop визуальный** - перемещение задач между колонками не изменяет статус в 1С
2. **Статус "На проверке"** - временный, в 1С мапится как "В работе"
3. **Кэширование фильтров** - фильтры не сохраняются между сессиями

## 🔄 Обновление проекта

Для обновления существующего проекта:

1. Скопируйте новые файлы в соответствующие пакеты:
   - `model/KanbanStatus.kt`
   - `ui/components/` - все файлы канбана
   - Обновите `MainActivity.kt` (замена CalendarView на CalendarWithKanbanView)

2. Убедитесь, что зависимости корректны:
   - Compose версии совместимы
   - Kotlin datetime библиотека присутствует

3. Соберите проект и протестируйте.
